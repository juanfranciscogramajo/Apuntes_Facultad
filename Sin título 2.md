| **Nombre del caso de uso:** | Finalizar viaje                                                                                                                                                                                                                                                                                                                                                     |                                                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Descripción:**            | Este caso de uso describe como un conductor finaliza un viaje                                                                                                                                                                                                                                                                                                       |                                                                                                             |
| **Actores:**                | Conductor                                                                                                                                                                                                                                                                                                                                                           |                                                                                                             |
| **Precondiciones:**         | Haber ejecutado el caso de uso "Iniciar Viaje"                                                                                                                                                                                                                                                                                                                      |                                                                                                             |
| **Curso Normal:**           | **Acciones del Actor**                                                                                                                                                                                                                                                                                                                                              | **Acciones del sistema**                                                                                    |
|                             | Paso 1: El conductor presiona el boton "Finalizar viaje"                                                                                                                                                                                                                                                                                                            | Paso 2: El sistema registra la finalizacion del viaje                                                       |
|                             | Paso 4: El conductor presiona el boton "confirmar"                                                                                                                                                                                                                                                                                                                  | Paso 3: El sistema solicita confirmacion si se supero el tiempo de carga esperado                           |
|                             | Paso 6: El conductor ingresa el monto a añadir                                                                                                                                                                                                                                                                                                                      | Paso 5 si se excedio el tiempo estimadosi                                                                   |
|                             |                                                                                                                                                                                                                                                                                                                                                                     | Paso 5.1: El sistema muestra monto original.                                                                |
|                             |                                                                                                                                                                                                                                                                                                                                                                     | Paso 5.2: El sistema suma el recargo ingresado al monto original                                            |
|                             |                                                                                                                                                                                                                                                                                                                                                                     | Paso 8: Se ejecuta el caso de uso "Pagar con tarjeta"                                                       |
|                             |                                                                                                                                                                                                                                                                                                                                                                     | Paso 9: El sistema registra el pago, se finaliza el viaje y se notifica que "Viaje finalizado exitosamente" |
| **Curso Alterno:**          | **Paso Alternativo 3:** La tarjeta ingresada no se encuentra registrado, se notifica en display y fin de caso de uso.<br>**Paso Alternativo 6:** Transcurren 45 segundos sin apoyar la bicicleta, el sistema bloquea el receptor, se cancela la operación, se notifica en display y fin caso de uso.<br>**Paso Alternativo 8:** El cobro falla, se vuelve a paso 7. |                                                                                                             |
| **Postcondición:**          | Se devuelve una bicicleta dejando registrado el identificador de la bicicleta y fecha de devolucion.                                                                                                                                                                                                                                                                |                                                                                                             |

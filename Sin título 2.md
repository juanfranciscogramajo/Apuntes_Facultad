| **Nombre del caso de uso:** | Finalizar viaje                                                                                                                                                                                                                                                                                                                                                     |                                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| **Descripción:**            | Este caso de uso describe como un conductor finaliza un viaje                                                                                                                                                                                                                                                                                                       |                                                                                             |
| **Actores:**                | Conductor                                                                                                                                                                                                                                                                                                                                                           |                                                                                             |
| **Precondiciones:**         | Haber ejecutado el caso de uso "Iniciar Viaje"                                                                                                                                                                                                                                                                                                                      |                                                                                             |
| **Curso Normal:**           | **Acciones del Actor**                                                                                                                                                                                                                                                                                                                                              | **Acciones del sistema**                                                                    |
|                             | Paso 1: El conuctor presiona el boton "Finalizar viaje"                                                                                                                                                                                                                                                                                                             | Paso 2: El sistema                                                                          |
|                             | Paso 5: El usuario registrado pone la bicicleta                                                                                                                                                                                                                                                                                                                     | Paso 3: El sistema verifica que la tarjeta tenga un alquiler activo.                        |
|                             |                                                                                                                                                                                                                                                                                                                                                                     | Paso 4: El sistema libera el receptor durante 45 segundos.                                  |
|                             |                                                                                                                                                                                                                                                                                                                                                                     | Paso 6: El sistema detecta la bicicleta.                                                    |
|                             |                                                                                                                                                                                                                                                                                                                                                                     | Paso 7: Se ejecuta el caso de uso "Cobrar alquiler"                                         |
|                             |                                                                                                                                                                                                                                                                                                                                                                     | Paso 8: El sistema registra el pago, se retiene la bici y se marca la bicicleta como libre. |
| **Curso Alterno:**          | **Paso Alternativo 2:** La tarjeta ingresada no se encuentra registrado, se notifica en display y fin de caso de uso.<br>**Paso Alternativo 6:** Transcurren 45 segundos sin apoyar la bicicleta, el sistema bloquea el receptor, se cancela la operación, se notifica en display y fin caso de uso.<br>**Paso Alternativo 8:** El cobro falla, se vuelve a paso 7. |                                                                                             |
| **Postcondición:**          | Se devuelve una bicicleta dejando registrado el identificador de la bicicleta y fecha de devolucion.                                                                                                                                                                                                                                                                |                                                                                             |

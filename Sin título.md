5. Sistema de alarmas Una empresa de seguridad ha solicitado el desarrollo de un sistema de alarma inteligente para el hogar. Este sistema se basa en una red de sensores que monitorean la actividad tanto dentro como alrededor de la vivienda. 
   Los residentes de la casa interactúan con el sistema a través de un panel de control físico, desde el cual pueden <font color="#ffff00">armar y desarmar la alarma.</font> Además, tienen la capacidad de <font color="#ffff00">activar una alarma silenciosa</font> en situaciones de emergencia. Para hacerlo, <font color="#00b0f0">deben ingresar un código especial; si el código es correcto, el sistema registra el evento</font> y se comunica con un <font color="#ff0000">servidor central</font> para notificar el incidente, permitiendo así que se tomen las medidas adecuadas. 
   El sistema cuenta con un perfil de administrador, que posee las mismas funciones que un <font color="#ff0000">usuario estándar</font>, pero con privilegios adicionales. El <font color="#ff0000">administrador</font> tiene la capacidad de <font color="#ffff00">actualizar la configuración del sistema de alarma</font> y <font color="#ffff00">modificar los códigos de acceso</font>. 
  <font color="#00b0f0"> Cada 15 segundos</font>, el sistema realiza una <font color="#ffff00">verificación de todos los sensores.</font> Si uno de los <font color="#ffff00">sensores se activa</font>, e<font color="#00b0f0">l sistema registra los datos del evento (fecha, hora, lugar de la vivienda, sensor) y activa la alarma. De inmediato, se inicia un proceso de comunicación con el servidor central para reportar el incidente. </font>
   Para establecer contacto con el <font color="#ff0000">servidor central</font>, <font color="#00b0f0">el sistema marca un número telefónico. Una vez que la central acepta la conexión, solicita al sistema el identificador de la alarma y los datos del evento. A continuación, el servidor devuelve un tiempo estimado de llegada de un móvil que el sistema debe almacenar. Si la línea telefónica se encuentra ocupada o la central rechaza la conexión, el sistema debe seguir insistiendo hasta que la conexión se concrete.</font>

## 8. Retiro de paquetes| Locker Inteligente para Retiro de Paquetes
Modele, mediante un diagrama de transición de estados, el funcionamiento de un locker inteligente para el retiro de paquetes.
El locker cuenta con un <font color="#00b0f0">display LCD </font>para mostrar mensajes de operación y el estado del retiro, un <font color="#00b0f0">teclado numérico</font> para ingresar códigos de retiro y los <font color="#00b0f0">botones encender y apagar.</font>
Para poner en funcionamiento el locker, el usuario <font color="#7030a0">presiona encender</font>.<font color="#ff0000"> El sistema activa el display y habilita el teclado numérico.</font> Luego, el usuario <font color="#7030a0">debe ingresar un código de retiro de 6 dígitos</font>. Al <font color="#ff0000">ingresar el último dígito, el sistema verifica que el código corresponda a un paquete disponible para retirar</font>. Si el código es válido, <font color="#ff0000">muestra en el display el número del compartimento asignado y desbloquea automáticamente la puerta del compartimento. </font>Si el <font color="#7030a0">código no es válido</font>, <font color="#ff0000">emite dos pitidos y solicita un nuevo ingreso.</font>
Si el <font color="#7030a0">usuario ingresa tres códigos incorrectos consecutivos,</font> el <font color="#ff0000">sistema bloquea temporalmente el teclado durante 30 segundos.</font> Durante ese tiempo, <font color="#ff0000">muestra en el display un mensaje indicando que debe esperar y una cuenta regresiva</font>. Una vez transcurrido el plazo, habilita nuevamente el teclado y permite ingresar otro código.
Una vez desbloqueada la puerta, el usuario dispone de 60 segundos para retirar el paquete. El compartimento cuenta con un <font color="#00b0f0">sensor</font> que permite detectar si el paquete permanece en su interior. Si el usuario<font color="#7030a0"> cierra la puerta retirando el paquete,</font> el<font color="#ff0000"> sensor detecta su ausencia y el sistema bloquea la puerta, emite tres pitidos,</font> <font color="#ff0000">muestra en el display «Paquete retirado»</font> y finaliza la operación, quedando el retiro del paquete como completado.
Si el usuario <font color="#7030a0">cierra la puerta sin retirar el paquete</font>, el sensor detecta que este permanece en el compartimento. En ese caso, el sistema <font color="#ff0000">bloquea la puerta, muestra en el display «Paquete no retirado.</font> Ingrese nuevamente el código de retiro» y permite ingresar nuevamente un código de retiro. <font color="#7030a0">Si transcurren los 60 segundos sin que el usuario haya retirado el paquete,</font> el sistema <font color="#ff0000">bloquea la puerta, emite un pitido de advertencia y permite ingresar nuevamente un código de retiro.</font>
Por último, el usuario puede presionar apagar en cualquier momento en que la puerta del compartimento esté cerrada. Al hacerlo, el sistema finaliza su funcionamiento y queda preparado para volver a encenderse e iniciar una nueva operación.
